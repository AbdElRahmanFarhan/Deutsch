description: Prepare a German speaking session for the Claude app and give the learner the trigger prompt. Use when the learner says speak or wants speaking practice from Claude Code.
---

Read `workflows/common.md` and `workflows/handoff.md`. Claude Code can't hold a voice conversation,
so prepare one for the Claude app: build a Brief as `workflows/speak.md` step 0 describes, create
the Handoffs row as `handoff.md` → "Sending a handoff to the Claude app" describes, and give the
learner the trigger prompt `Deutsch handoff: <URL>` in a code block. Notion ids: `notion/ids.json`.
