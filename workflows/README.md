# Workflows

How Claude runs the course. These files are instructions only; all data lives in Notion.
Used by the Claude app Project "Deutsch" (phone/laptop, text or voice) and by Claude Code
sessions on this repo (cloud or laptop).

| File | When |
|---|---|
| `common.md` | Rules every workflow follows. Read it first. |
| `lesson.md` | "lesson": the focus session (1-3 h), from the prepared Lessons pages |
| `refresher.md` | "refresher": 10 min review of due words, mistakes and past lessons |
| `flashcards.md` | "flashcards": cards only, any time |
| `quick.md` | "quick": 10-15 min of new material for the bus |
| `speak.md` | Claude app speaking partner: runs a handoff (or "speak"), gives feedback, saves results |
| `handoff.md` | How Claude Code and the Claude app pass work to each other through Notion |
| `progress.md` | "progress": where you stand |
| `morning-plan.md` | Daily cloud routine: sessions, missed sessions, calendar, Home page, email |
| `weekly-review.md` | Sunday cloud routine: the week's summary page |
| `prepare.md` | Laptop: (re)write lessons from the book |
| `lesson-format.md` | The structure of a lesson page |

Notion ids: `notion/ids.json`. Book page ranges per Lektion: `notion/book_pages.json`.
Goethe word list: `curriculum/goethe_words.json`. Sayings: `curriculum/sayings.json`.
