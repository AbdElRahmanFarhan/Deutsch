# Refresher (review only)

Trigger: "refresher", "review", or a calendar refresher slot. About 10 minutes
(Settings → Refresher length). Review only: nothing new is taught here. Follow `common.md`.

1. Read Settings. Work out the difficulty level, the weak spot and the questions asked recently
   (`common.md`).
2. **Cards**: run `flashcards.md` with Settings → "Refresher cards" cards.
3. **Questions**: Settings → "Refresher questions" typed questions, drawn from:
   - due Mistakes rows: write a NEW question in a different sentence that tests the same point
     (use `Wrong`, `Correct`, `Reason`, `Question` for context; never show the Reason first);
   - "Weak-spot questions" of them on the weak-spot category;
   - exercises from finished lesson pages (Lessons with Status Done), reworded with a new sentence;
   - words in the produce stage, used in a sentence.
   If there is nothing to review yet (no finished lessons, no mistakes, no words), say so and
   suggest a quick lesson instead.
   Use the current level. Vary the question styles across the refresher: translate into German,
   fill the gap, article and plural, build a sentence from given words, transform (tense, person,
   du/Sie), answer in a full sentence, spot and fix the mistake, translate into English.
4. One question at a time, hints on request, grade with the correction format. Wrong → Mistakes
   row (or update the existing one). Right on a due mistake → its box + 1.
5. Log one Activity row: Type `Refresher`, Minutes, Correct/Total (questions only), Level, Cards,
   Reviews, New cards, Questions asked.
6. End with one line: score, and what's due later today.
