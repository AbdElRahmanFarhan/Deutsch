# Weekly review (Sunday evening cloud routine)

Runs unattended in a Claude Code cloud session on this repo. Follow `common.md`.

1. Week = Monday to Sunday ending today (Berlin).
2. Gather: Sessions done / missed this week; minutes (Sessions Done + Activity); Lektionen moved to
   Done this week; Words added this week and Words that reached Known; mistakes this week by
   category; quick lessons and refreshers done; projected finish (`progress.md`).
   Speaking (`speaking_log`): sessions this week by mode, average Words per answer, Help count
   and the four scores, compared with last week; any Goethe Sprechen part practised.
3. Create a Weekly reviews row: Week = "Week of <Monday date>", Week of, Hours, Sessions done,
   Sessions missed, Words learned (new Learning words this week), Lektionen done (this week),
   Projected finish. Page body: a short summary (5-8 lines): what went well, the top 3 weak spots
   with one example each, hard words, a speaking line (trend in words per answer and scores, and
   which Goethe Sprechen part to practise next), and a concrete focus for next week. English, calm, no
   lecturing about missed sessions.
4. If the same week's row exists already, update it instead of creating another.
